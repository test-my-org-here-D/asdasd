# AGENTS.md

Guidance for coding agents working in this repository.

## Overview

This is a test repository. It has no application code.

- `README.md`: short description of the repository.
- `test`: a placeholder text file that contains the word "test".

## Workflow

- Create a new branch for every change. Do not commit on `main`.
- Keep changes small and focused on the task.
- Write clear, imperative commit messages.
- Push to the working branch. Do not open a pull request unless asked.

## Hygiene

- Do not commit secrets or tokens.
- Do not put credentials in URLs, commands, configuration, or output.
- Do not change git user configuration.
- Do not add `Co-authored-by` or `Signed-off-by` trailers.

## Later changes

- Add tests when new code warrants them.
- Keep `README.md` in sync when files are added, removed, or renamed.
- Update this file when a real command or convention appears. Do not invent one before then.
