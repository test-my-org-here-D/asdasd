# AGENTS.md

Guidance for AI coding agents working in this repository.

## Repository overview

This is a test repository with no application code.

- `README.md`: short description of the repository.
- `test`: a placeholder text file containing the word "test".

## Workflow

- Create a new branch for every change. Never commit directly to `main`.
- Keep changes small and focused on the task.
- Write clear, imperative commit messages.
- Push to the working branch. Do not open pull requests unless asked; automation handles that.

## Conventions

- Keep `README.md` in sync when files are added, removed, or renamed.
- Do not commit secrets or tokens, and do not put them in URLs or config.
- Do not set `git user.email` or add `Co-authored-by` or `Signed-off-by` trailers.
- Add tests when code is introduced and the change warrants them.
